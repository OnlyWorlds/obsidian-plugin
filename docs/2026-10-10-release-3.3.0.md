# 3.3.0 — World units; the legacy-template code removed

*Released 2026-10-10 (tag 3.3.0). This is the release body.*

World units, and the old template code removed.

- **World units.** The OnlyWorlds standard 00.31.00 gives a world three units: length, mass and distance. `World.md` now has a Units section with a line for each (`Length Unit`, `Mass Unit`, `Distance Unit`), free text such as `cm`, `stone` or `leagues`. They are labels; nothing converts, and the stored value stays a plain number.
- **Shown in Properties.** The nine numbers that use a unit show it beside the value, as in `182 cm`: Character and Creature height and weight, Creature speed, Object and Species weight, Ability range and Location elevation. A world with no unit set shows the bare number, as before.
- **Synced.** Download World writes the server's units into `World.md`, and adds the Units section to a `World.md` made before this version. Upload World sends a unit when you changed it. Only the world's owner can change the units; a co-builder's upload still uploads the elements and says the units were not sent. Copy World and Export as OnlyWorlds folder carry the units too.
- **Old template code removed.** The plugin no longer carries the pre-3.0 template downloader. Nothing used it since 3.0.0, and the templates it pointed at were deleted upstream on 2026-07-28. Old `PluginFiles/Templates` and `PluginFiles/Handlebars` folders in a vault are harmless; delete them if you like.

Each change carries a test (suite 144/144).
